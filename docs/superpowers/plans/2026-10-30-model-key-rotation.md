# Qrent 专用模型 Key 轮换

用户已要求停止使用旧 Key、新建专用 Key，并在配置完成后自行充值。当前所有模型请求保持停止，继续使用唯一正式账本、原评分规则和生产表结构。

1. 准备独立 Key：仅爬虫服务器固定 IPv4、仅固定版本 `qwen3.7-flash-2026-07-15`；在创建长期访问凭据的提交点取得浏览器规则要求的确认。共享 OCR 旧 Key 的云端禁用范围由用户在同次确认选择；异常旧 Key 始终保持禁用。
2. 为新模型使用 DashScope 多模态接口，输入只含文本，显式关闭思考和搜索、限制输出，保持一次 HTTP、不自动重发和提供商暂停机制。北京短输入档每百万 tokens 为 CNY 0.2 / 0.8；超过 32K 的输入先拒绝，不隐式进入更贵的档位。
3. 复用相同描述、提示词和评分参数下已经完整验收的旧模型缓存，保留实际缓存模型来源，避免换 Key/模型重算已完成记录。部分或不确定调用保留，不据此启动原全量队列。
4. 先完成离线测试与受控 SSH 部署。创建后设置云端 CNY 50/月、达额停止；新 Key 只写入私有服务器环境，保留原账本和旧 Key 暂停标记。人工启动标记继续缺省，原全量队列不自动恢复。
5. 验证 Key 掩码、权限、预算、服务停止状态和账本调用数不变，告知用户可以充值。充值后的质量小样本与正式恢复另取实际运行证据；不把凭据已配置称作模型效果或全量发布完成。
