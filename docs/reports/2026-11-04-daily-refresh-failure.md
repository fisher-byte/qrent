## 故障链路

1. Domain 原普通香港出口的公开 JSON 搜索从 11 月 2 日起返回 HTTP 403。11 月 4 日对同一出口、同一公开 URL 的普通 HTML 请求也返回 `403 Access Denied`。日志证明访问被拒绝；无法仅据此确定对方具体的拒绝规则。
2. 原采集保留 Real Estate 成功结果，并记录 Domain 22 个失败查询。两轮受控恢复仍收到 403。
3. `ops/recover_school_capture.py` 在两轮耗尽后返回 1；`ops/run_school_capture.sh` 继续返回失败。
4. 根 `run_scraper.sh` 仅在子入口返回 0/2 时启动 enrichment。当前返回 1，因此没有新模型、通勤和生产发布阶段。

当前完整窗口规则及恢复边界见 [10 月 31 日恢复记录](2026-10-31-school-capture-recovery.md)：仅完整 41/41 才生成恢复成功报告，daily/prepare 不接受局部 success。该规则使单一来源失败影响全部新发布。
